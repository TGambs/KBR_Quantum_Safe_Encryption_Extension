## ML-KEM768 Chrome Browser Extension
#### Created by Tommaso Gambro as part of 4th Year Dissertation at Heriot Watt University

This extension uses the NIST standardised ML-KEM768 key encapsulation mechanism along with AES encryption to provide an easy to use interface for Post-Quantum key generation, encryption, decryption, and key storage.

It utilises Chrome's built in browser storage "Chrome.storage.local", however it is reccomended to not enter any personally identifiable data as the storage itself is not encrypted in any way. This may be fixed in future updates.

This extension remains 'unpacked' until some security concerns are dealt with.

Follow this to use on your local machine:
- Clone the repo
- Open the "Manage Extensions" page in the Chrome browser
- Select 'Load Unpacked'
- Choose the cloned dir 'KBR_Browser_Extension'
