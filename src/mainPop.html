Step by step usage

Encryption:

  1. Generate your own key pair
  2. Get the public key of the message receiver
  3. Encrypt your message with their public key
  4. Send all the data (ct, iv, mssg) to the recipient

Decryption:

  1. Recieve the message encrypted with your public key
  2. Ensure it is formatted as (ct, iv, mssg)
  3. Use your private key to decrypt the message

<-> This extension utilises KYBER-768 key encapsulation together with AES for post-quantum message encryption. All data saved is stored locally on your device and can be fully deleted with the button below if needed.

<-> Public keys can be shared with anyone, other people need your public key to send you messages.
<-> DO NOT share private keys with anyone, these must be kept secret. Copying them to a password protected text file is recommended.

<-> All encrypted messages MUST have the exact text "ct = ", "iv = ", "mssg = ", otherwise it will not be able to be read it.

<-> Public keys are not personally identifiable on their own, so it is advised that you choose the reference carefully. Using names or other identifying information as references could reveal who you are communicating with if your device is ever accessed by someone else.

<-> If using keys generated outside of this extension, make sure it has been formatted with base64 encoding or it won't work.

<-> If an error popup shows, do not check the box unless you don't want future popups to show.

<-> The storage allows for a maximum amount of 1000 key pairs and 1000 public key / reference pairs.

<-> The maximum amount of text that can be encrypted is ~63,000 characters
